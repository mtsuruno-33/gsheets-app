プライバシーポリシー（cc-booster sheets）

制定日: 2026年10月15日

1. 取得する情報

Google アカウントでログインした際に、次の情報を Google から受け取ります。

  • ログインしたアカウントのメールアドレス（取り違え防止の照合のみに使用）
  • 利用者が指定した Google スプレッドシートの内容
  • Google が発行する認証トークン

2. 利用目的

利用者本人の指示に従って、指定したスプレッドシートを読み取り・書き込みするためだけに使います。広告・分析・機械学習モデルの学習には使いません。

3. 保存

認証トークンは利用者本人の Mac のキーチェーンにのみ保存します。スプレッドシートの内容を別のサーバーへ保存することはありません。

4. 第三者提供

取得した情報を第三者に提供・販売しません。通信先は Google のサーバーのみです。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. 削除

利用者は Google アカウントの「サードパーティによるアクセス」 からいつでもアクセス権を取り消せます。取り消すと保存済みトークンは無効になります。

English summary

cc-booster sheets is a personal tool used only by its owner. It accesses the owner's email address and the Google Sheets the owner specifies, solely to read and write those sheets on the owner's instruction. Tokens are stored only in the owner's macOS Keychain. No data is sold, shared with third parties, or sent anywhere other than Google. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
